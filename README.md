# Marisa Mancuello

Sitio web personal de Marisa Mancuello, Contadora Pública (UBA) y Especialista en Finanzas.

Landing estática, responsive y bilingüe (español e inglés), con información de servicios, acceso a la comunidad de WhatsApp y agenda de consultas.

## Uso local

Abrí `index.html` en un navegador. No requiere instalación de dependencias ni proceso de compilación.

Los recursos y novedades se comparten en el [grupo de WhatsApp](https://chat.whatsapp.com/G0GoP51IZWuJAmMIJXmsBA).
