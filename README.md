# Marisa Mancuello

Sitio web personal de Marisa Mancuello, Contadora Pública (UBA) y Especialista en Finanzas.

La web es una landing estática, responsive y bilingüe (español e inglés), con información de servicios, recursos descargables y agenda de consultas.

## Uso local

Abrí `index.html` en un navegador. No requiere instalación de dependencias ni un proceso de compilación.
